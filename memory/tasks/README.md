# Tareas (CAPA 2 · BEADS)

Cada archivo `<task-id>.md` guarda el estado de una tarea para que **sobreviva** cambios de modelo,
sesión o límite. Secciones estándar: `Plan`, `Implementación`, `Gates`, `Review`, `Deploy`.

El control-plane escribe aquí automáticamente (ver `apps/control-plane/src/memory.ts`).
